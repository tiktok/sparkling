# Create a new Sparkling app

Create a Sparkling app using the official scaffolder, then use the bundled workflow CLI to build
Lynx bundles and run the native shells.

## Quick Start

If you want a runnable project in minutes:

<Steps>

### Create a new project

```bash
npm create sparkling-app@latest my-app
cd my-app
```

### Run native targets

```bash
# Android
npm run run:android

# iOS
npm run run:ios

# HarmonyOS
npm run run:harmony
```

### Add Sparkling methods as needed

```bash
npm install sparkling-storage
```

### Build bundles for release

Same command regardless of package manager:

```bash
npx sparkling build
```

</Steps>

### What you get

- A Lynx app project (based on the default template)
- Android, iOS, and HarmonyOS native shells created together
- A working JS ↔ native pipe method example (router)
- Developer workflow commands (build / autolink / run)

Key folders/files created by the default template:

- `src/`: Lynx/React entry points and assets
- `android/`, `ios/`, `harmony/`: native shells; HarmonyOS embeds Lynx directly
- `app.config.ts`: build + routing config consumed by `sparkling-app-cli`
- `package.json`: scripts (`dev`, `build`, `run:android`, `run:ios`, `run:harmony`)

### Prerequisites

- Node.js **22** or **24** (required by Sparkling tools)
- A Node package manager of your choice (`pnpm`, `npm`, `yarn`, or `bun`)
- For running native shells:
  - Android Studio / Android SDK (Android) / JDK 11
  - Xcode 16+ + iOS Simulator (iOS)
  - Ruby (≥3.2.6, &lt;3.4) for iOS build
  - DevEco Studio or HarmonyOS Command Line Tools with SDK 6.0.0 (API 20), including `ohpm`, `hvigorw`, and `hdc` (HarmonyOS)
